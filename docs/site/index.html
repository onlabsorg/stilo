Documents that do the math

Stilo is the editor for Texl documents: reports and calculations whose numbers compute themselves, and that link to the documents they use. You write them as a stack of lines, like a spreadsheet you can read as a report.

Learn the editor Get started

Why Stilo

The words and the numbers of your work, in one living document.

Feels like Excel

A document is a sheet of numbered lines. Select a line, press Enter to edit it, Ctrl+Enter to see the result: the lines below follow.

Reads like Word

Headings, lists, tables and emphasis, written in Markdown and shown formatted. The formulas sit right in the text.

Linked, not copied

A document imports the values of another one: a library of materials, a colleague's calculation. When that changes, yours follows.

Plain files

Every document is one text file in your folder. Keep it in git, open it in any text editor, render it without Stilo.

Notes on every line

Comments live in the document, next to the line they are about, and move with it.

Yours to run

One command serves a folder on your computer or your own server. Free software, under the MIT license.

Two commands

stilo serve opens a folder in the web editor. stilo render prints a document with its formulas computed.

  • Edit in the browser, save to plain .texl files.
  • Every document has one address, for people and for imports.
  • Render reports from scripts and build pipelines.
